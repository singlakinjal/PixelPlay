About This Project

This website is a capstone project for the SNW (Web Development) subject.

The core challenge is to build a complete, two-phase project that showcases an understanding of web fundamentals.

Project Details

  • Theme: Games
  • Mentor: Ajay Sharma sir
  • Reference: Minecraft.net

Phases

  • Phase 1 (Mid Evaluation): A static website built with HTML and CSS. This includes the main layout, color scheme, and page structure.
  • Phase 2 (Final Evaluation): A dynamic website with JavaScript functionalities. This involves adding the playable games (like Tic-Tac-Toe and Snake) to the portal.
